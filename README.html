glyhub

glyhub collects glycomics and glycoproteomics data for the Glycoverse ecosystem, using the GlycomicSE and GlycoproteomicSE containers from glyexp. The package is experimental.

Available data

Eleven glycomics objects are bundled from two public studies. No glycoproteomics datasets are included yet.

GPST000738 retains both enzyme experiments and all raw-table feature rows. Conflicting cells are NA; this is not a complete reconstruction of the authors’ final analytical matrix. Flow and time are conditions, and a repeated control table is represented once per enzyme. Unmatched processed-table observations remain in metadata without invented sample pairing.

GPST000643 uses complete supplementary quantitative tables for separate experiments. Tables S10B and S10C have distinct N/O feature spaces and are split accordingly. Each pair retains the same source observation columns and original denominators. Source labels do not establish biological replication or cross-table pairing.

Zero-valued abundances are stored as NA in the distributed assays. Original values, source n.d./NA, conflict masks and zero-to-NA records are retained separately in metadata. Metadata zeros (such as 0 hours) are unchanged. Measurements are not imputed or renormalized. Read the curation audit for source selection, units, annotation precision, licenses and limitations.

Installation

Install the development version from GitHub:

# install.packages("pak")
pak::pkg_install("glycoverse/glyhub")

Example

x <- glyhub::glyhub_GPST000738_N_B4GalT1
dim(x)
#> [1]  9 18
data.frame(as.list(S4Vectors::metadata(x)$processing_counts))
#>   source_missing source_nd conflict zero_to_na
#> 1              0         0       24          6

Data use R’s LazyData mechanism. SummarizedExperiment::assay(x) contains the curated abundance matrix; S4Vectors::metadata(x)$raw_abundance preserves the unconverted values. rowData(x) retains typed glyrepr annotations and source evidence, and colData(x) retains source conditions and observation locations.

Reproduction

Original inputs and scripts are grouped by accession under data-raw/GPST000643/ and data-raw/GPST000738/. From the package root:

source("data-raw/build.R")
# Check that rebuilding preserves scientific contents:
source("data-raw/validate-reproduction.R")

See validation results. See ?glyhub_data_conventions for shared measurement and annotation conventions.
