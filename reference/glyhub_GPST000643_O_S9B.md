# GH2 treatment of bovine submaxillary mucin O-glycans

O-glycan-derived LC-MS profiles from bovine submaxillary mucin treated
with six Bacteroides thetaiotaomicron GH2 enzymes. The experiment
compares galactosidase activity on an intact complex mucin glycan
substrate, including its sialylated and substituted forms. Supplementary
Table S9B contains 56 features and seven observations.

## Usage

``` r
glyhub_GPST000643_O_S9B
```

## Format

A
[glyexp::GlycomicSE](https://glycoverse.github.io/glyexp/reference/GlycomicSE.html)
with 56 features and 7 observations. The abundance assay is in
percentage of source total glycan AUC.

## Source

GlycoPOST GPST000643. Supplementary Table S9B (media-10.xlsx). Study:
<https://doi.org/10.64898/2026.03.26.714468>. Repository:
<https://glycopost.glycosmos.org/entry/GPST000643>.

## Details

The seven source columns represent a control and separate treatments
with BT1626, BT3179, BT3340, BT4050, BT4241 and BT4684. No replicate
labels are supplied for these columns. This table concerns bovine
submaxillary mucin without the sialidase/fucosidase pretreatment used in
the separate S9C experiment.

Abundances are percentages of total source glycan AUC. Source galactose,
sialylation, sulfate and fucose annotations accompany the molecular
labels. A single column per condition should not be interpreted as
replicated evidence for treatment effects.

Typed compositions cover the 56 features, with 40 encoded putative
structures. Unresolved linkage descriptions remain in their original
notation.
