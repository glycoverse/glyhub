# Colonic mucin O-glycan degradation by enzyme mixtures

Porcine colonic mucin oligosaccharide profiles after treatment with a
Bacteroides thetaiotaomicron enzyme mixture, with or without BT3868. The
experiment tests how adding this GH20 enzyme changes the residual
glycans and digestion products after combined removal of terminal
residues and substituents. Supplementary Table S11B contains 60 features
across nine observations.

## Usage

``` r
glyhub_GPST000643_O_S11B
```

## Format

A
[glyexp::GlycomicSE](https://glycoverse.github.io/glyexp/reference/GlycomicSE.html)
with 60 features and 9 observations. The abundance assay is in
percentage of source total glycan AUC.

## Source

GlycoPOST GPST000643. Supplementary Table S11B, sheet named Table 11B
(media-12.xlsx). Study: <https://doi.org/10.64898/2026.03.26.714468>.
Repository: <https://glycopost.glycosmos.org/entry/GPST000643>.

## Details

Three source-labelled samples are reported for each of a no-enzyme
control, an eleven-enzyme mixture and the same mixture supplemented with
BT3868. The base mixture contains BT0455, BT4243, BT1625, BT3173,
BT1636, BT1624, BT1626, BT4241, BT1628, BT4681 and BT0438. This is the
S11B mixture; it does not include the additional BT4394 used in the
distinct S11C experiment.

Measurements are percentages of source total glycan AUC. O-derived
features include remaining substrate glycans and released enzymatic
products. Sample 1-3 labels are retained without assigning a biological
replicate type or pairing the conditions.

Compositions are typed for all features and 27 putative structures are
encoded. Ambiguous structural text remains available for the other
features.
